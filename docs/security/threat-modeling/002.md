# STRIDE --- Denial of Service (DoS)

**Endpoint:** `GET /api/v1/products/{id}`\
**Riesgo:** Alta\
**Categoría:** Denial of Service

## Amenaza

Un atacante puede enviar un volumen elevado de solicitudes al endpoint,
provocando un consumo excesivo de recursos en **Kong**, el microservicio
**Products** y la **DB**.

## Diagrama

``` mermaid
flowchart LR
    A[Atacante] -->|Miles de GET| K[Kong API Gateway]
    K --> P[Products Microservicio]
    P --> DB[(DB)]

    K -.->|Saturación| K
    P -.->|CPU / Memoria| P
    DB -.->|Consultas excesivas| DB
```

## Impacto

-   Incremento de CPU y memoria.
-   Saturación de conexiones y consultas a la DB.
-   Respuestas lentas o timeouts.
-   Indisponibilidad para usuarios legítimos.

## Mitigaciones

-   **Rate limiting** en Kong.
-   WAF y detección de tráfico anómalo.
-   Límites de concurrencia y timeouts.
-   Caching cuando sea aplicable.
-   Monitoreo y alertas de CPU, memoria y conexiones a DB.

### Resultado

> Un atacante puede explotar el endpoint mediante un alto volumen de
> solicitudes, afectando la disponibilidad del microservicio y sus
> dependencias.
